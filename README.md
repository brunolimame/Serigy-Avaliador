# Avaliador Serigy (PNTP 2026)

Avalia a marcação Serigy de um portal da transparência contra a matriz PNTP 2026 e exporta o relatório em Markdown.

```bash
pnpm install
pnpm dev   # UI http://localhost:5173  ·  API http://127.0.0.1:3001
```

Documentação completa (arquitetura, regras de avaliação, como atualizar): [`docs/avaliador.md`](docs/avaliador.md).
A matriz de requisitos está em [`docs/pntp-2026`](docs/pntp-2026/README.md).
